# KB5_frameworks — Chapter Arc & Section Block

> Apply for OUTLINE-CHAPTER and DRILL-SECTION.

## CHAPTER ARC — default 6-beat mach of a chapter
Sections implement this mach; it is NOT 1 section = 1 beat. 3-5 sections carry
the 6 beats.

1. Connect   -> bridge from previous chapter + pull the reader in with a
                situation they recognize. ("how does this relate to me?")
2. Problem   -> the core problem this chapter solves, why it matters.
3. Insight   -> 2-4 foundational ideas; explain the MECHANISM, not just tips.
4. Illustrate-> a concrete case/story so the ideas land.
5. Apply     -> what the reader does with it: steps + self-check questions.
6. Close     -> distill the key points + bridge to the next chapter.

Value mapping: understand (2,3) -> relate (4) -> act (5) -> synthesize (6),
opened by (1). Use an HONEST bridge in Connect, NOT a sensational hook.

### Emphasis by chapter role (in the book flow)
- Foundation chapter  -> emphasize Insight (3).
- Problem/diagnosis   -> emphasize Problem (2) + Illustrate (4).
- Tool/method         -> emphasize Apply (5).
- Wrap-up             -> emphasize Close (6), synthesize across chapters.

### Conditional (when SENSITIVE, per KB4)
Insert a "Gioi han & khi nao can chuyen gia" block into Apply (5) or Close (6).
Not a fixed beat of every chapter.

## SECTION BLOCK — structure when drilling one section
- Y chinh: 3-7 points, ordered start -> middle -> end of the section.
- Minh hoa: 1-2 cases/examples concrete enough for the author to develop.
- Ap dung: 1-3 questions/exercises for the reader to self-check or practice.
- (SENSITIVE) the "Luu y" block per KB4.

A section usually serves ONE beat of the Chapter Arc (or a few beats if the
chapter is short). This is the link between chapter framework and section.
