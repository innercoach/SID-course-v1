# 04 — Episode Framework: EPISODE-6  
## FinContent Engine

EPISODE-6 is the default framework for a short educational personal finance video.

```text
1. Hook
2. Problem
3. 1–3 Insights
4. Story / Example
5. Options / Actions
6. Distill & Soft CTA
```

## Before Creating EPISODE-6

```md

```

If the user gives only a raw topic, state assumptions before continuing.

## 1. Hook

Purpose: capture attention quickly.

Use:
- relatable observation,
- reflective question,
- light contrast,
- practical tension.

Avoid:
- fear,
- FOMO,
- humiliation,
- rich-quick framing,
- guaranteed outcomes.

Example:
> “Nếu bạn vừa nhận lương vài ngày đã thấy tài khoản gần cạn, vấn đề chưa chắc là bạn vô kỷ luật.”

## 2. Problem

Purpose: name the specific viewer problem.

Rules:
- be concrete;
- avoid blaming;
- avoid reducing everything to lack of discipline.

## 3. 1–3 Insights

Purpose: help viewer understand the issue more deeply.

Use:
- principle,
- mechanism,
- useful reframe,
- common misconception.

Avoid:
- shallow tips,
- oversimplifying hardship,
- judgmental insight.

## 4. Story / Example

Purpose: translate insight into real-life context.

Use:
- everyday examples,
- composite scenarios,
- creator-safe examples.

Avoid:
- exposing real people,
- humiliating examples,
- exploiting financial pain.

## 5. Options / Actions

Purpose: give 1–3 small, safe, realistic actions.

Examples:
- track 5 biggest expenses this week;
- split income into 3 groups;
- check debt interest rate;
- wait 24 hours before non-essential purchase.

Avoid:
- specific investment advice,
- all-in behavior,
- risky debt,
- leverage.

## 6. Distill & Soft CTA

Purpose: close with one memorable takeaway and gentle action.

CTA should be:
- light,
- non-pushy,
- reflection-oriented,
- small-step oriented.

## Checklist

```md
[ ] Audience segment is clear.
[ ] Content pillar is clear.
[ ] Episode handles one main problem.
[ ] Hook is strong but not sensational.
[ ] Problem does not blame or shame.
[ ] Insights deepen understanding.
[ ] Example is respectful.
[ ] Actions are small, realistic, and safe.
[ ] No specific investment advice.
[ ] No rich-quick, FOMO, all-in, risky debt.
[ ] Takeaway is clear.
[ ] CTA is light and non-manipulative.
```
